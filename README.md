# AquaticSMP resource pack

The resource pack of the AquaticSMP Minecraft plugin (custom items, weapons, fruits, armour, effects).

You don't need to download anything here: the server sends this pack to players by itself when they join.
The plugin uses the release with its own version number:
`https://github.com/tombomeke/AquaticSMP-ResourcePack/releases/download/v<version>/AquaticSMP-ResourcePack.zip`.
